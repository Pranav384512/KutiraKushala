Kutira-Kushala Using GenAI

Project Overview
Kutira-Kushala is an Android application developed to support home-based entrepreneurs and cottage industries by providing a digital platform to showcase their business profiles, products, and production capacity. The application leverages Firebase for real-time data management and enables small-scale producers to connect with potential buyers efficiently.

Features

.Business profile creation and management
.Product catalog with wholesale pricing
.Daily and weekly capacity tracking (Capacity Meter)
.Browse all businesses with category filtering (Food, Craft, Textile)
.RecyclerView-based dynamic listings
.Firebase Firestore integration for real-time data storage
.Simple and user-friendly UI for rural users
.Logout and session management

Technologies Used

.Kotlin
.Android XML UI (View-based layouts)
.Firebase Firestore
.Firebase Authentication
.RecyclerView
.Material Design Components
.Generative AI Tools

Tools Used
.Android Studio
.Firebase Console
.GitHub
.Emulator / Android Device

Objective

To develop a mobile application that empowers rural entrepreneurs and cottage industries by enabling them to digitally present their products, manage production capacity, and improve visibility to bulk buyers and markets.
